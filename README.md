# 诗词阁 · 本地古诗词检索

把 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 的全唐诗、全宋词抓下来做成的本地网页，双击即用，不联网也能查。

数据规模：**唐诗 57,603 首 · 宋词 21,046 首 · 作者 5,177 位**（其中 2,561 位带作者小传）。

## 怎么用

双击 `启动.bat`，或者直接双击 `index.html`，用默认浏览器打开即可。

如果浏览器对本地脚本有限制，可以在本目录下执行：

```
python -m http.server 8000
```

然后访问 http://localhost:8000 。

## 能做什么

- **全库检索**：标题、作者、正文一起搜，多个词用空格分开表示「且」的关系，比如 `李白 明月`。繁简都能搜，输入简体也能命中繁体原文。
- **作者筛选**：左侧列表是作品数量最多的 20 位，点一下只看他的作品，再点一下取消。
- **随机一首**：从当前范围里随机抽，没筛选就是全库。
- **繁简切换**：右上角按钮。原文是繁体，默认显示简体，点一下看繁体原貌。
- **详情**：点开任意一篇，能看到全文、作者小传，支持一键复制。
- **滚动加载**：往下滑自动加载下一批，也可以点「再看一些」。快捷键 `/` 聚焦搜索框，`Esc` 关闭详情。

## 目录结构

```
index.html        页面
app.js            检索与交互逻辑
build_data.py     把 raw/ 的分片合并成 data/ 下的前端数据
fetch_data.py     从仓库下载原始分片
data/
  dict.js         繁简对照表（2,903 个字）
  authors.js      作者小传
  tang.js         唐诗（13.1 MB，首屏加载）
  song.js         宋词（5.6 MB，切到宋词时才加载）
raw/              84 个原始分片，34 MB，可随时重建 data/
```

## 数据说明

- 数据来自 chinese-poetry 仓库，MIT 协议，可自用、可商用，但保留版权声明。
- 原文是繁体，页面用逐字对照表转简体，不做词组级别的语义转换，极少数一字多义的场合可能不够准确。
- 这个数据集沿用较早的版本，个别篇目和现在通行的选本不同。比如《静夜思》收的是「牀前**看**月光，疑是地上霜；舉頭望山**月**，低頭思故鄉」，所以直接搜「床前明月光」是搜不到的。遇到这类情况，用作者名或标题搜都能定位到。
- 原始数据由早期爬取而来，少量字句可能有错讹，仓库本身还在持续修订。

## 更新数据

```
python fetch_data.py     # 重新抓取分片（会自动跳过已下载的）
python build_data.py     # 重新合并成 data/*.js
```

`fetch_data.py` 已经配了国内可访问的镜像源，因为本机直连 `raw.githubusercontent.com` 的 TLS 握手会被阻断。
